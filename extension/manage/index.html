Search Hugging Face from your address bar

Type hf then Tab or Space in your browser's address bar to search Hugging Face models, datasets, spaces, and more.

Query Classes

Use @keyword to filter by type:

  • @model — search models
  • @dataset — search datasets
  • @space — search spaces
  • @org — search organizations
  • @user — search users
  • @paper — search papers
  • @collection — search collections
  • @bucket — search buckets

Examples: @dataset llama, llama @model, or just llama to search both models and datasets.
